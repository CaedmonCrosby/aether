# AETHER

**Cosmic Synthesizer** — An interactive instrument for the stars.

![AETHER](https://github.com/CaedmonCrosby/aether/raw/main/preview.png)

Double-click `index.html` (or open it in any browser) to play. Pure single-file experience — no install, no build step, no external dependencies after the page loads.

## Controls

- **Keyboard piano**: 
  - White keys: `Z X C V B N M , . /`
  - Black keys: `S D   G H J`
  - `[` and `]` shift octave
  - `SPACE` triggers a random beautiful chord

- **Mouse on the canvas**: Drag to strum the cosmic strings and trigger notes. The visuals react instantly.

- **Sliders**: Shape both the sound (cutoff, resonance, reverb, delay) and the visuals (flow, particle density, hue, brightness) in real time.

- **Presets**: Nebula Choir, Crystal Strings, Plasma Lead, Void Bass, Aurora Pads — instant gorgeous starting points.

- **Snapshot**: Download the current visual state as a crisp PNG.

- **Auto Jam**: Let it play itself while the nebula breathes.

## What you are experiencing

A rich polyphonic synthesizer (multiple detuned oscillators + noise + filters + lush delay/reverb) driving a living 2D particle system and physically simulated glowing energy "strings". Everything is reactive: notes excite the strings, spawn particles, and shift the energy of the nebula.

Built in one session as a demonstration of what is possible when you say "Impress me."
